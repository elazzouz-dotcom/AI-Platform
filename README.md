# تطبيق طلبات المشاريع المحلي

تطبيق محلي بسيط لتلقي الطلبات وحفظها في ملف JSON، بدون إرسال البيانات إلى خدمة خارجية.

## التشغيل

```bash
cd /home/ubuntu/local-leads-app
npm start
```

افتح في المتصفح:

```text
http://127.0.0.1:3000
```

لإيقاف التطبيق:

```text
Ctrl + C
```

## وضع التطوير

```bash
npm run dev
```

## مكان حفظ الطلبات

```text
data/leads.json
```

## ملاحظات أمنية

- التطبيق مناسب للاستخدام المحلي أو داخل شبكة موثوقة.
- قبل نشره على الإنترنت أضف تسجيل دخول، تحديد معدل الطلبات، HTTPS، ونسخاً احتياطية.
- لا تضع بيانات حساسة داخل ملف JSON أو مستودع عام.
